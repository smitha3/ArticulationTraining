# 🎯 Articulation Trainer

An AI-powered articulation training application designed to help you master clear, concise, and compelling communication in just 30 days.

![React](https://img.shields.io/badge/React-18.0-blue) ![AI](https://img.shields.io/badge/AI-Claude%20Sonnet%204-purple) ![License](https://img.shields.io/badge/License-MIT-green)

---

## ✨ Features

### 🎓 **4 Comprehensive Training Phases**
1. **Structure Training (10 min)** - Organize thoughts into clear 3-point structures
2. **Recorded Speaking (15 min)** - Practice articulation with self-scoring
3. **Compression Drill (10 min)** - Master concise expression (60s → 30s → 15s)
4. **Precision Upgrade (10 min)** - Eliminate fillers and refine delivery

### 🤖 **AI-Powered Features**
- **Topic Suggestions** - AI generates training topics across 10 learning domains
- **Intelligent Feedback** - Claude Sonnet 4 provides structured analysis with:
  - Assessment of your performance
  - Identified issues
  - Specific solutions with before/after examples
  - Improved versions of your content
  - Key takeaways
  
### 📊 **Progress Tracking**
- 30-day training program
- Session history with detailed scores
- Streak counter
- Performance metrics: Clarity, Conciseness, Flow, Fillers
- Category statistics across 10 learning domains

### 🎨 **Beautiful UI**
- Dark/Light mode toggle
- Glassmorphism design
- Smooth animations
- Professional typography (Outfit + Space Mono)
- Responsive layout

## 🚀 Getting Started

### **Option 1: Use with Claude.ai (Recommended)**
1. Go to [Claude.ai](https://claude.ai)
2. Upload `articulation-trainer-final.jsx`
3. Ask Claude to run it
4. Start training!

### **Option 2: Local Development**
```bash
# Clone the repository
git clone https://github.com/YOUR-USERNAME/articulation-trainer.git
cd articulation-trainer

# Install dependencies (if you have a React setup)
npm install

# Run the app
npm start
```

## 📖 How to Use

### **Daily Workflow:**

1. **Start Your Session**
   - Open the app
   - See your current day (X/30)
   - Click "Start Today's Training"

2. **Pick a Topic**
   - Enter your own topic, or
   - Click a category for AI-generated suggestions
   - Choose difficulty: Beginner, Intermediate, or Advanced

3. **Complete All 4 Phases**
   - Follow the timer for each phase
   - Check off tasks as you complete them
   - Get AI feedback on your performance

4. **Track Your Progress**
   - View session history
   - See score trends
   - Monitor your improvement over 30 days

## 🔧 Tech Stack

- **Frontend:** React with Hooks
- **AI:** Anthropic Claude API (Sonnet 4)
- **Icons:** Lucide React
- **Styling:** Tailwind CSS utility classes
- **Storage:** Browser localStorage with async persistence
- **State Management:** React useState and custom useStorage hook

## 💾 Data Persistence

**Note:** Data persists across sessions but is local to your browser.
